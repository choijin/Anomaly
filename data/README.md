# Dataset files

Run `uv run metropt download`, then `uv run metropt prepare`.
`raw/` and `processed/` are ignored by Git. Original archive and CSV checksums
are pinned in `src/anomaly_detection/data.py`.

[MetroPT-3](https://archive.ics.uci.edu/dataset/791/metropt+3+dataset), Davari,
Veloso, Ribeiro, and Gama (2021),
[DOI: 10.24432/C5VW3R](https://doi.org/10.24432/C5VW3R),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

See [data and evaluation notes](../docs/data.md) for sensor coverage,
annotations, sampling, and splits.
