# Data files

`uv run metropt download` fetches the checksum-verified source;
`uv run metropt prepare` creates minute snapshots. Both stay outside Git.

Source: Davari, Veloso, Ribeiro, and Gama (2021),
[MetroPT-3](https://doi.org/10.24432/C5VW3R),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See [data notes](../docs/data.md).
